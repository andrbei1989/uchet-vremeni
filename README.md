# Учёт рабочего времени

Отметки прихода и ухода по QR-кодам с GPS. Статическое приложение: работает в браузере,
данные — в localStorage, одноразовая авторизация телефонов — в Google Таблицах.

**Приложение:** https://andrbei1989.github.io/uchet-vremeni/

## Как это устроено

- **Два общих QR на входе** — постеры «ВХОД» и «ВЫХОД», одинаковы для всех, висят у двери.
- **15 регистрационных QR** — по одному на сотрудника, выдаются один раз.
- **PIN-а нет.** Сканирование регистрационного QR авторизует телефон: приложение запоминает
  сотрудника и ключ устройства у себя. Сотрудник ничего не вводит и ничего не видит.
- **Отметка** — сотрудник сканирует общий постер «ВХОД» или «ВЫХОД». Приложение само
  определяет, кто это, запрашивает GPS и показывает подтверждение.
- **Одноразовость** — при первой авторизации телефон записывается в лист «Регистрации» вместе
  с Device ID. Тот же код на другом телефоне получить доступ не сможет. Администратор может
  отозвать доступ — отметки с этого телефона сразу перестанут приниматься.

### Важно про ключи в QR

Список сотрудников хранится в браузере каждого устройства отдельно, ключи в нём генерируются
случайно при первом запуске. Поэтому **QR, напечатанный на компьютере администратора, содержит
ключ, которого нет в памяти телефона**. Приложение считает ключ из QR актуальным и авторизует
телефон по нему — печатать коды можно с любого устройства.

Если код перевыпущен, новый QR тоже принимается: телефон просто перепривязывается к новому ключу.

## Настройка (5 минут)

1. Создайте Google Таблицу.
2. Меню **Расширения → Apps Script**.
3. Вставьте код из файла `apps-script.gs` (он же есть в приложении: Настройки → «Показать код Apps Script»).
4. **Развернуть → Новое развёртывание → Веб-приложение**. «Запуск от имени»: **Я**,
   «У кого есть доступ»: **Все**. Скопируйте ссылку, оканчивающуюся на `/exec`.
5. Приложение → **Настройки** → вставьте ссылку → **Проверить соединение**.
6. Включите тумблеры «Проверять код при регистрации» и «Проверять доступ при отметке».

Листы «Отметки» и «Регистрации» создаются автоматически при первом запросе.
Если таблица создавалась в предыдущей версии — удалите лист «Отметки», структура колонок изменилась.

## Разделы приложения

| Раздел | Что делает |
|---|---|
| Сканер | Камера и распознавание QR, кто авторизован на телефоне, последние отметки |
| Табель | Часы, смены, опоздания за период, детализация по дням, экспорт CSV |
| QR-коды | Постеры «ВХОД»/«ВЫХОД» и 15 регистрационных кодов, печать A4 и сеткой 3×5 |
| Сотрудники | ФИО, активность, кто авторизован и с какого устройства, отзыв доступа |
| Настройки | URL таблицы, геозона офиса, рабочее время, код администратора, бэкап |

Код администратора по умолчанию: **1234**. Спрашивается при отзыве доступа и перевыпуске QR.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `app-core.js` — хранилище, QR, камера, авторизация, отметки
- `app-views.js` — экраны, навигация, действия
- `apps-script.gs` — серверная часть для Google Таблиц
- `.github/workflows/publish.yml` — служебный workflow, который кладёт файлы в репозиторий

> Файлы обновляются workflow-ом: правки в `index.html` и скриптах через веб-интерфейс GitHub
> будут перезаписаны при следующей публикации. Сначала удалите workflow.

## Требования

Камера и геолокация работают только по HTTPS — GitHub Pages это обеспечивает.
Открывать нужно в обычной вкладке браузера (Chrome/Safari), а не во встроенном превью.
После обновления приложения на телефоне может понадобиться обновить страницу (потянуть вниз
или очистить кэш), иначе браузер продолжит работать со старой версией скриптов.
