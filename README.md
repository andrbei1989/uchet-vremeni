# Учёт рабочего времени

Веб-приложение для отметок прихода и ухода сотрудников по QR-кодам с фиксацией GPS-координат.
Статическая версия: работает целиком в браузере, данные хранятся в localStorage, а одноразовая
регистрация сотрудников — в Google Таблицах.

**Приложение:** https://andrbei1989.github.io/uchet-vremeni/

## Как это устроено

- **Два общих QR на входе** — постеры «ВХОД» и «ВЫХОД». Одинаковы для всех сотрудников, висят у двери.
- **15 регистрационных QR** — по одному на сотрудника, выдаются один раз.
- **PIN сотрудника** — 6 цифр, вычисляется из кода регистрации и хранится в телефоне сотрудника.
  При отметке PIN подставляется автоматически: сотрудник только сканирует общий QR.
- **Одноразовость** — при первой регистрации телефон записывает привязку в лист «Регистрации».
  Повторное использование того же кода на другом телефоне блокируется. Администратор может
  отозвать доступ — тогда отметки с этого телефона перестанут приниматься.

## Настройка (5 минут)

1. Создайте Google Таблицу.
2. Меню **Расширения → Apps Script**.
3. Вставьте код из файла `apps-script.gs` (он же есть в приложении: Настройки → «Показать код Apps Script»).
4. **Развернуть → Новое развёртывание → Веб-приложение**. «Запуск от имени»: **Я**,
   «У кого есть доступ»: **Все**. Скопируйте ссылку, оканчивающуюся на `/exec`.
5. Откройте приложение → **Настройки** → вставьте ссылку в поле URL → **Проверить соединение**.
6. Включите тумблеры «Проверять код при регистрации» и «Проверять доступ при отметке».

Листы «Отметки» и «Регистрации» создаются автоматически при первом запросе.

## Разделы приложения

| Раздел | Что делает |
|---|---|
| Сканер | Камера + распознавание QR, ручной ввод PIN, последние отметки |
| Табель | Часы, смены, опоздания за период, детализация по дням, экспорт CSV |
| QR-коды | Постеры «ВХОД»/«ВЫХОД» и 15 регистрационных кодов, печать A4 и сеткой 3×5 |
| Сотрудники | ФИО, активность, PIN, статус регистрации, отзыв доступа |
| Настройки | URL таблицы, геозона офиса, рабочее время, код администратора, бэкап |

Код администратора по умолчанию: **1234**. Это не PIN сотрудника — он защищает просмотр PIN-ов.

## Файлы

- `index.html` — разметка
- `styles.css` — стили
- `app-core.js` — хранилище, QR, камера, регистрация, отметки
- `app-views.js` — экраны, навигация, действия
- `apps-script.gs` — серверная часть для Google Таблиц
- `.github/workflows/publish.yml` — служебный workflow, который кладёт файлы в репозиторий

> Файлы приложения обновляются workflow-ом. Если правите вручную через веб-интерфейс GitHub,
> сначала удалите `.github/workflows/publish.yml`, иначе следующая публикация перезапишет правки.

## Требования

Камера и геолокация работают только по HTTPS — GitHub Pages это обеспечивает.
Открывать нужно в обычной вкладке браузера (Chrome/Safari), а не во встроенном превью.
