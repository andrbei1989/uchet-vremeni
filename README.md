# Учёт рабочего времени

QR-коды + Google Таблица. Сотрудник не устанавливает приложение и не знает ссылку на него:
он только сканирует QR-коды обычной камерой телефона.

**Панель администратора:** https://andrbei1989.github.io/uchet-vremeni/

## Как это работает

1. **Привязка телефона (один раз).** Администратор добавляет сотрудника и выдаёт ему личный QR-код.
   Сотрудник наводит на него камеру → открывается страница «Телефон привязан».
   Сервер выдаёт телефону секретный ключ. Личный код после этого больше не срабатывает:
   второй телефон по нему не привяжется.
2. **Вход и выход.** У двери висят два QR-кода — «ВХОД» и «ВЫХОД». Сотрудник наводит камеру →
   «Вход отмечен, 09:02, на рабочем месте». В Google Таблицу пишутся дата, время (по часам сервера),
   координаты, расстояние до рабочего места и вердикт «в зоне / вне зоны / без координат».
   Отметку принимают только с привязанного телефона.
3. **Администратор** входит по паролю: **«На смене»** — кто сейчас на работе (обновляется раз в минуту),
   **«Табель»** — смены, часы, опоздания за период и выгрузка в CSV, **«QR-коды»** — печать,
   **«Сотрудники»** — добавить, переименовать, сменить телефон, заблокировать.

## Настройка (10 минут, один раз)

1. Создайте Google Таблицу → **Расширения → Apps Script** → удалите всё и вставьте код из `apps-script.gs`.
2. **Развернуть → Новое развёртывание → Веб-приложение**: «Запуск от имени: Я», «Доступ: Все».
   Скопируйте ссылку на `/exec`.
3. Откройте панель администратора, вставьте ссылку и придумайте пароль администратора.
4. **Настройки**: координаты рабочего места, радиус, рабочее время → «Сохранить».
5. **Сотрудники**: добавьте людей. **QR-коды**: распечатайте «ВХОД/ВЫХОД» и личные коды.

### Обновление серверного кода

Apps Script → вставить новый код → **Развернуть → Управление развёртываниями → ✎ →
Версия: «Новая версия» → Развернуть**. Ссылка `/exec` останется прежней, QR-коды перепечатывать не нужно.
(«Новое развёртывание» создаёт новую ссылку — тогда коды придётся печатать заново.)

## Автоматика (версия 5)

- **Правка отметок.** Табель → ✎ в строке дня: аннулировать ошибочную отметку или добавить забытую.
  Ручные отметки помечаются «вручную», аннулированные остаются в таблице с пометкой.
- **Автозакрытие.** Ночью смены без выхода закрываются с пометкой «авто»; часы за них не считаются,
  пока администратор не поправит выход.
- **Telegram.** Сразу — отметки вне зоны и без геопозиции; утром — кто не пришёл; вечером — итоги дня.
  Настройки → «Уведомления в Telegram».
- **Резервные копии.** По воскресеньям в 3:00 — копия таблицы в папку
  «Учёт рабочего времени — резервные копии» на Google Диске, хранятся 8 последних.
- **Табель Excel.** Табель → «Табель Excel за месяц»: часы по дням + лист со всеми сменами.

Автоматике нужен разовый доступ: Apps Script → выбрать функцию `installAutomation` → «Выполнить» → «Разрешить».

## Что где хранится

- **Сотрудники** — лист «Сотрудники»: код, ФИО, ключ QR, статус, телефон, дата привязки, секрет телефона.
- **Отметки** — лист «Отметки»: дата, время, код, ФИО, тип, координаты, точность, расстояние, зона.
- **Настройки** — лист «Настройки»: координаты и радиус рабочего места, рабочее время.
- **Пароль администратора** — в свойствах скрипта, в виде хэша.

## Файлы

- `index.html`, `app.js`, `xlsx.js`, `styles.css` — панель администратора
- `emp.html` — страница сотрудника (открывается только из QR)
- `apps-script.gs` — сервер для Google Таблиц

## Ограничения

- Геолокация работает только в обычном браузере телефона (Chrome), не в режиме инкогнито.
- Если сотрудник очистит данные браузера, телефон придётся привязать заново:
  «Сотрудники» → «Сменить телефон» → новый QR.
- Координаты сообщает телефон. Подмену GPS специальными приложениями это не исключает,
  но такие отметки обычно видны по неестественной точности и повторяющимся координатам.
