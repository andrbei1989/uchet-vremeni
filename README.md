# Учёт рабочего времени

QR-коды-ссылки + Google Таблица как журнал. Сотрудник не заходит в приложение: он сканирует
QR обычной камерой телефона, и всё происходит на открывшейся странице.

**Приложение администратора:** https://andrbei1989.github.io/uchet-vremeni/
**Страница сотрудника (открывается сама из QR):** https://andrbei1989.github.io/uchet-vremeni/emp.html

## Как это работает

1. **Привязка (один раз).** Сотрудник сканирует свой регистрационный QR камерой Android или iPhone
   → открывается `emp.html` → «Телефон привязан». Телефон запоминает сотрудника и ключ устройства.
   Второй телефон по тому же коду уже не привяжется.
2. **Вход и выход.** У двери висят два постера-ссылки «ВХОД» и «ВЫХОД». Сотрудник наводит камеру →
   открывается та же страница → «ВХОД отмечен, 09:12, в допустимой зоне». Запись уходит в Google Таблицу
   с датой, временем, координатами и вердиктом по геозоне.
3. **Администратор.** Открывает приложение: вкладка **«На смене»** показывает, кто сейчас на работе,
   во сколько вошёл и был ли в зоне; **«Табель»** подтягивает все отметки из таблицы за период;
   **«QR-коды»** печатает постеры и 15 регистрационных кодов; **«Сотрудники»** — привязки и отзыв доступа.

QR-коды — это обычные ссылки, поэтому работают со штатным сканером. Ссылки не публикуются и
никуда не рассылаются: сотрудник получает их только с распечатанного кода.

## Настройка (10 минут, один раз)

1. Создайте Google Таблицу → **Расширения → Apps Script** → вставьте `apps-script.gs`.
2. **Развернуть → Новое развёртывание → Веб-приложение**, «Запуск от имени: Я», «Доступ: Все».
   Скопируйте ссылку на `/exec`.
3. Приложение → **Настройки** → вставьте ссылку → **Проверить соединение**.
4. **Настройки → Геозона офиса**: «Взять текущие» (или впишите координаты вручную) и
   **«Сохранить геозону в таблицу»**. После этого «в зоне / вне зоны» считает сервер, а не телефон.
5. **QR-коды** → «Печать A4» для вход/выход и «Печать всех» для регистрационных кодов.
   Если адрес таблицы менялся, QR нужно напечатать заново — он зашит в ссылку.

Листы «Отметки», «Регистрации», «Настройки» создаются автоматически.

## Что где хранится

- **Журнал отметок** — лист «Отметки»: дата, время, код, ФИО, тип, широта, долгота, точность,
  расстояние до офиса, «в зоне / вне зоны / без координат», источник, устройство, метка ISO.
- **Привязки** — лист «Регистрации»: код, ФИО, ключ устройства, Device ID, устройство, статус.
- **Офис** — лист «Настройки»: `office_lat`, `office_lng`, `radius_m`.

## Файлы

- `index.html` — приложение администратора
- `emp.html` — страница сотрудника (открывается из QR)
- `styles.css`, `app-core.js`, `app-views.js` — код администратора
- `apps-script.gs` — серверная часть для Google Таблиц
- `.github/workflows/publish.yml` — служебная публикация файлов

> Файлы обновляются workflow-ом. Правки через веб-интерфейс GitHub будут перезаписаны при
> следующей публикации — сначала удалите workflow.

## Ограничения, о которых стоит знать

- Камера и геолокация работают только по HTTPS (GitHub Pages это даёт) и только в обычной вкладке
  браузера, а не во встроенном превью.
- Приложение администратора показывает данные из таблицы; если сотрудник отметился секунду назад,
  нажмите «Обновить» (автообновление — раз в минуту).
- Отметка без координат не сохраняется: страница требует геопозицию. Если сотрудник вне зоны,
  запись создаётся, но помечается «вне зоны» с расстоянием.
- Ссылка на `emp.html` без параметров бесполезна — она просто объясняет, что открывать её вручную не нужно.
